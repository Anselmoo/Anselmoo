Inter is self-hosted and ships roman only, so every <em> here was a browser-synthesised oblique — the roman mechanically skewed, which is not a cut anyone drew. It was also unstable: the metric fallbacks carry real italics, so emphasis changed shape between the fallback and the webfont. font-synthesis: none refuses the fake, which makes the gap visible instead of plausible. Emphasis takes the carrier this system already uses everywhere else — one variable weight step, 500, short of the 600 a subhead uses, so emphasis inside a sentence cannot be read as a heading. The second row is the other half: the audience line was italic because the system had no word for it. It is a deck, and now it is a slot — an existing size named for a purpose, never a new step. Shipping the real Inter italic supersedes all of this.
