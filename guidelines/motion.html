Motion

Two tokens, and that is the set

--motion-fast120ms
Colour and opacity. Not a new number: it is the --transition-fast that sat unused in the Cupertino review flow, now with a consumer.
--motion-easecubic-bezier(0, 0, 0.58, 1)
The CSS Easing Level 1 definition of ease-out, written out. A hand-tuned curve would be four numbers with no source.
120 ms · --motion-fast
200 ms · guard boundary
Colour and border-colour cross at 120 ms. Nothing moves, so nothing needs a guard.

Under 200 ms, colour and opacity need no prefers-reduced-motion guard. Transform and position need one always — and get no token here, because no surface in this system moves. A third dead motion token is the defect this file was written to repair, not repeat.

One band: motion is structural and band-independent, so a second band would show the same two numbers twice. The one thing that differs between bands — which colour a transition crosses to — is already the Colors cards' evidence.
