OG lab

Renders every file in assets/og/ at its full 1200 × 630 and offers the PNG a feed will actually accept. Nothing here generates an image — npm run og does that. This only turns one format into another.

The rasteriser needs Inter. A font loaded by this page does not reach inside an <img>, so the SVG resolves the family against the system. Without Inter installed it falls back to Helvetica Neue or Arial, both measured 5.3 % narrower, and size-adjust cannot correct a face it cannot see.
